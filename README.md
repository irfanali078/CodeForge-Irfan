# 🚀 Patient Management API

This is a FastAPI-based backend project to manage patient records.

## 🔥 Features
- Add new patient
- View all patients
- View single patient
- Update patient details
- Delete patient
- Calculate BMI automatically
- Sort patients (height, weight, bmi)

## 🛠️ Tech Stack
- Python
- FastAPI
- Pydantic
- JSON (as database)
